# Data

| File | Created by | Description |
|------|-----------|-------------|
| `imdb_reviews.csv` | included | 8,000 reviews (4,000 positive / 4,000 negative), columns `review`, `sentiment` |
| `imdb_test_gold.csv` | Notebook 01 | 20% held-out test reviews with their true labels |
| `imdb_weak_labeled.csv` | Notebook 01 | training reviews with majority-vote weak labels |
| `imdb_augmented.csv` | Notebook 02 | weak-labeled reviews + augmented minority-class reviews |

**Source:** `imdb_reviews.csv` is a random, class-balanced sample (duplicates removed, `random_state=7`) of the
[IMDB Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)
(Maas et al., 2011). A copy of the full dataset is in this repo at `Labs/GCP_Labs/Compute_Engine_Labs/Lab2/IMDb_Reviews.csv`.

Only `imdb_reviews.csv` is committed; the other files are regenerated by running the notebooks.
